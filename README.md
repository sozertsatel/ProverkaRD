# Проверка РД

Настольная программа для сверки рабочей документации одного этапа. Сопоставляет четыре источника:

- акт сдачи-приёмки РД (DOCX);
- ведомость ВЭРД (XLSX, лист «База»);
- ведомость ВЭСР (XLSX, лист «ВЭ»);
- комплекты РД (PDF или DOCX) и отсоединённую подпись `<файл>.sig`.

Расхождение, которое не снимается нормализацией оформления, помечается как **Критично**. Совпадение после нормализации (пробелы и переносы, регистр, точка в конце, «ПК 5859» и «ПК5859», неразрывный пробел, кавычки) — **Ошибка оформления**. Лишняя фамилия в подписи — **Предупреждение**. Криптографию ГОСТ программа не проверяет: из подписи читаются только фамилии сертификатов подписантов.

Версия сборки — 0.0.1. Она стоит в заголовке окна и в первой строке каждого листа отчёта.

При запуске программа молча спрашивает последний релиз `sozertsatel/ProverkaRD`. Кнопка «Проверить обновления» делает то же самое. Если тег `vX.Y.Z` новее установленной версии, показывается сообщение со ссылкой на страницу релизов. Без сети проверка ничего не показывает. Закрытый репозиторий без входа отвечает 404: это «проверить не удалось», и страница релизов всё равно открывается по кнопке.

## Запуск

Нужен SDK .NET 8.

```bash
dotnet run --project src/ProverkaRD.App
```

Сборка одного exe для Windows (x64, со средой выполнения внутри файла):

```bash
dotnet publish src/ProverkaRD.App -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true
```

Готовый файл — один `ProverkaRD.exe`. Сжатие внутри пакета не меняет состав: среда выполнения и нативные библиотеки по-прежнему внутри файла и распаковываются при запуске.

Проверка без окна, с записью отчёта:

```bash
dotnet run --project src/ProverkaRD.App -- --check \
  --verd samples/etap7.xlsx \
  --vesr samples/vesr.xlsx \
  --acts samples/akty \
  --rds samples/rd \
  --out отчёт.xlsx
```

## Как пользоваться

1. «Загрузить ВЭРД» и «Загрузить ВЭСР» — в строке остаются имена файлов.
2. Слева — комплекты РД (файлы, папка или перетаскивание). Файл `.sig` рядом подхватывается сам.
3. Справа — акты тем же способом.
4. «Проверить» заполняет таблицы. Красная строка — критично, жёлтая — оформление, оранжевая — предупреждение, зелёная — совпадает.
5. «Выгрузить отчёт (Excel)» пишет книгу из трёх листов: «Сводка», «Комплекты», «Замечания». В шапке указана версия программы.
6. «Проверить обновления» сверяет версию с последним релизом на GitHub.

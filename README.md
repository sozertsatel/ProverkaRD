# Проверка РД

Настольная программа для сверки рабочей документации одного этапа. Сопоставляет четыре источника:

- акт сдачи-приёмки РД (DOCX);
- ведомость ВЭРД (XLSX, лист «База»);
- ведомость ВЭСР (XLSX, лист «ВЭ»);
- комплекты РД (PDF или DOCX) и отсоединённую подпись `<файл>.sig`.

Расхождение смысла, цифр, номеров ПК или пропущенное «ПК» помечается как **Критично**. Совпадение после нормализации (пробелы, невидимые символы, похожая латиница, регистр, точка, «ПК 5859» и «ПК5859») и опечатка в одну-две буквы — **Ошибка оформления**. Фамилия из тома, которой нет в `.sig`, — критично; лишние люди в подписи не показываются. Криптографию ГОСТ программа не проверяет: из подписи читаются только фамилии сертификатов подписантов.

Версия сборки — 0.0.3. Она стоит в заголовке окна и в первой строке каждого листа отчёта. История изменений — в `CHANGELOG.md` и в окне «О программе».

При запуске программа молча спрашивает последний релиз `sozertsatel/ProverkaRD`, если в настройках включена проверка обновлений. Кнопка «Проверить обновления» делает то же самое. Если тег `vX.Y.Z` новее установленной версии, показывается текст релиза и кнопки «Обновить» и «Позже». «Обновить» скачивает `ProverkaRD.exe`, сверяет размер и `ProverkaRD.exe.sha256`, заменяет текущий файл и перезапускает программу. Если записать файл в папку нельзя, замена ставится в очередь до закрытия программы. Без сети тихая проверка ничего не показывает; кнопка сообщает об ошибке и открывает страницу релиза. Закрытый репозиторий без входа отвечает 404: это «проверить не удалось».

## Запуск

Нужен SDK .NET 8.

```bash
dotnet run --project src/ProverkaRD.App
```

Сборка одного exe для Windows (x64, со средой выполнения внутри файла):

```bash
dotnet publish src/ProverkaRD.App -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true
```

Готовый файл — один `ProverkaRD.exe`. Сжатие внутри пакета не меняет состав: среда выполнения и нативные библиотеки по-прежнему внутри файла и распаковываются при запуске.

Проверка без окна, с записью отчёта:

```bash
dotnet run --project src/ProverkaRD.App -- --check \
  --verd samples/etap7.xlsx \
  --vesr samples/vesr.xlsx \
  --acts samples/akty \
  --rds samples/rd \
  --out отчёт.xlsx
```

## Как пользоваться

1. «Загрузить ВЭРД» и «Загрузить ВЭСР» — в строке остаются имена файлов.
2. Слева — акты (файлы, папка или перетаскивание).
3. Справа — комплекты РД тем же способом. Файл `.sig` рядом подхватывается сам.
4. «Проверить» заполняет таблицы. Красная строка — критично, жёлтая — оформление, оранжевая — предупреждение, зелёная — совпадает.
5. «Выгрузить отчёт (Excel)» пишет книгу из трёх листов: «Сводка», «Комплекты», «Замечания». В шапке указана версия программы.
6. «Проверить обновления» в окне «О программе» скачивает новую сборку, если она есть.
